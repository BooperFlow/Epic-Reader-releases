# Epic Super Reader — releases

Installable APKs of **Epic Super Reader**, an e-book reader and audiobook player for
Android. Download `EpicSuperReader.apk` from the newest release on the
[Releases page](../../releases/latest).

The app checks this page for updates by itself and can download and install a new
version from inside the app (Settings → Check for updates).

This repository holds only the release files; the source code is not public.
